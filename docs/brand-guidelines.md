# CDPC 品牌指南（初版）

> 状态：概念阶段。CDPC 是当前项目使用的工作品牌名，正式发布前仍需进行商标、域名与同名产品检索。

## 品牌定位

CDPC 是面向像素艺术、方块风格角色、皮肤编辑、3D 预览与 AI 辅助创作的数字创作平台。品牌应传达：有创造力、现代、清晰、友好，并尊重创作者的自主表达。

**品牌主张：** Create Beyond Pixels.（让创作超越像素。）

## 视觉原则

- **深色创作空间：** 使用深色底色衬托作品，避免把整个页面做成高饱和霓虹效果。
- **像素作为符号：** 用方块、网格、切面与几何构成表达像素/体素主题，不直接照搬任何游戏的商标或专有界面。
- **渐变点缀：** 蓝紫色代表创意与数字工具，青色用于强调交互或状态。
- **内容优先：** 模板、角色、创作者作品应成为视觉主体，品牌装饰不可喧宾夺主。
- **响应式与可访问性：** 保证移动端导航、键盘操作、可读对比度和减少动态效果偏好。

## 字体与排版

- 拉丁标题：Manrope 或系统无衬线字体。
- 中文正文：Noto Sans SC 或系统中文无衬线字体。
- 技术标签：DM Mono 或等宽字体。
- 标题短而明确；正文控制行宽；避免过多大写和装饰性标签。

## 标志使用

- 使用仓库中的 `assets/icons/favicon.svg` 作为当前站点图标。
- 标志由四块像素组成，适用于深色背景。
- 不要拉伸、倾斜重绘或把标志与第三方商标组合。
- 当前标志属于初版视觉资产，正式商用前应进行相似性检索。

## 文案语气

- 清楚、鼓励探索、尊重创作者。
- 少用空泛的“革命性”“无限可能”等夸张宣传。
- 对尚未上线的功能使用“规划中”“概念展示”等准确表述。
- 不暗示与 Minecraft、Mojang 或 Microsoft 存在官方关联、背书或合作关系。
